# Open review findings

What the last whole-app review (2026-11-10: SOLID, DRY, KISS and security, four reviewers, each finding checked in the code) found and is not fixed yet, most severe first. Fix one with a test that fails first, then delete its line. The `health` skill (`.claude/skills/health/`) runs the next review; add to this list what it finds and doesn't fix.

Fixed in that review: `file:` media addresses from messages opened as local files (`LocalFileUrlTest`); `stt.command`/`stt.engine` travelling through the cloud (`SettingsSplitTest`); `natives.yml` gave every job a write token; an unreadable settings file was wiped on the next save (`SettingsSplitTest`); the window built before a language change or logout kept marking its chat read (`RelocalizeUiTest`); the Docker homeserver listened on every interface; `Redactor` let refresh tokens, cookies and YAML secrets through (`RedactorTest`); autosaved files could hide their extension (U+202E), be hidden (leading dot) and lacked Mark-of-the-Web (`FileNamesTest`, `MarkOfTheWebTest`); link and GIF bodies had no deadline or cap, and reserved ranges passed `LinkInspector` (`LinkInspectorTest`, `GifFilesTest`); deep HTML nesting overflowed the stack (`HtmlViewUiTest`); an animated WebP could declare frames enough to fill the disk (`BigWebpTest`); Codex ran with the person's MCP servers, rules and AGENTS.md (`ReplyWriterTest`); a login's `well_known` could move the session to plain http elsewhere (`LoginWellKnownTest`); ffmpeg could be handed a playlist that reads local files (`FfmpegInputTest`); quitting stopped the services on the UI thread, freezing the window (`ShutdownTest`); bridge and tuwunel downloads were checked against their own release's sums, now against hashes pinned in the app (`BinaryStoreTest`, `ManifestTest`). Medium findings fixed the same day: autosave marked failed saves done and skipped my own sends, and kept shell-active Windows files (`AutoSaveTest`, `SyncProcessorTest`, `FileNamesTest`); a 429/5xx at start threw away the sync cache, `m.direct` was overwritten after a failed read, failed reply lookups were cached, and `.part` files, pending events and download watchers leaked (`CatchUpErrorTest`, `BotChatDirectTest`, `ReplyLookupRetryTest`, `DownloadLeftoversTest`); pictures saved from links became MP4s, cloud repair loaded whole files, sign-ins never timed out and compared `state` with `equals`, pCloud's token stayed in history, HTTP bodies weren't closed (`VideoTranscoderTest`, `StorageDownloads`, `CloudSignInUiTest`); bridge configs and `tuwunel.toml` were world-readable and `config.yaml` was rewritten in place, links opened without a scheme check, Chrome's debugging port stayed 15 min, `natives.yml` pasted data into scripts, Docker images were `:latest` (`HomeserverConfigTest`, `BridgeConfigTest`, `BrowserTest`, `ChromeLoginTest`). Low findings, the DRY and most SOLID items fixed the next round: one way to run a program (`Processes`), to write a file (`support/SafeFile`), to coalesce a redraw (`ui/FxCoalescer`), to send to a cloud (`cloud/Http`), to parse an mxc (`model/Mxc`) and to name a MIME type (`MimeTypes`); `Composer`, `PreferencesFile` and `MatrixChatService` split; settings saved in the background; the tray built on AWT's thread; Discord pauses retried; autosave's lasting failures retried on a timer then let go; `ComposerHeightUiTest` fixed on Linux and `ui-headless` made blocking.
