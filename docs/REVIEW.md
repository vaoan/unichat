## Correctness
1. **`ComposerHeightUiTest.everyLineShowsWithoutScrolling` fails on Linux in every CI run** (`ui-headless`, informative, so the build stays green): after widening the composer from 420 to 880 px the text box never shrinks back (`never happened: it shrinks back when it needs less`); it passes on the Mac. Either `Composer.autoGrow` misses the re-wrap on Linux (it listens to the drawn `Text`'s layout bounds) or the box really can't shrink there. Reproduce on Linux (a container with the CI's Ubuntu 24.04 + `-Pheadless-ui`), then make `ui-headless` blocking once it's green.
2. **Autosave: a failure "for now" that never clears holds the chat** (`autosave/AutoSave`): by design it retries at each change and later files wait; a disk that stays full or an unrecognized yt-dlp error waits forever, and a quiet chat retries only at its next message. A cap, or a retry on a timer, is still open.
3. Lower: `Settings.save` fsyncs twice under the lock on every `set`; the tray is built on the FX thread (`ui/Notifier.java:173`); stopping `ReplyWriter`/`Transcriber` leaves their program running; an old `CloakJob` can write over the new one's status; `Transcripts` can start a note twice; renaming a group splits its folder; `BigPictures` downloads ffmpeg before trying `sips`; Discord server pause fails silently.
