# links — notes for Claude

`LinkInspector` opens the links in messages to find out whether they hold video or audio. The links come from anyone: no cookies, every hop (redirects included) refuses this machine and its network (loopback, private, link-local and reserved ranges, IPv6 forms that carry an IPv4), and a body should be read under a deadline (not yet: `HttpRequest.timeout` covers only the headers, so a server trickling bytes holds one of the 4 threads). The checks lean on the JVM's DNS cache between checking and connecting. More in `.claude/rules/ui-timeline.md`.
