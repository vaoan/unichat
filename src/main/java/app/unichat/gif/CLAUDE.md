# gif — notes for Claude

GIF search (`GifSearch` over `GifProviders`: `GiphyProvider`, `KlipyProvider`, each with the person's own key) and frame reading (`GifFrames`). Keys are `gif.<provider>.key`, kept on this machine (`Settings.staysOnThisMachine`). What a provider returns is a stranger's address: `GifFiles.download` takes https only (redirects never drop to http), stops past `MAX_BYTES` (20 MB) and reads the body under the same timeout as the headers (`support/BoundedBody`); a partial file is deleted. Tests reach a local http server through the package-private `fetch`, which skips only the scheme check.
