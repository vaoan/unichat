# voice — notes for Claude

Recording, cleaning and encoding voice notes. The rules, commands and map are in the root `CLAUDE.md`.

- Sending voice notes: `voice/` records from `Microphone` (Java Sound) and encodes Ogg/Opus in pure Java (`VoiceEncoder`, Concentus; `OggOpusWriter`); `ui/VoiceBar` replaces the composer row while recording. `voice/VoiceEnhancer` (`voice.enhance`) cleans the raw recording before sending with ffmpeg (highpass, RNNoise `arnndn`, speechnorm), downloading ffmpeg and the pinned model on first use; any failure sends it as recorded and says so. Two ffmpeg passes, noise then volume: chained in one, Homebrew's ffmpeg 9 never finished some notes (output stuck at 2^20 samples); each pass may take 15 s plus twice the note's length. While it works the composer shows "Preparando la nota de voz… N s" (`ui/WorkingLine`). Measure changes to the filter with speech (`say`), not tones: RNNoise leaves a tone alone. `VoiceEnhancerTest` does with `-Dunichat.networkTests=true`. `RoomFeatures.voiceSend` says, per chat, the MIME (WhatsApp needs `audio/ogg; codecs=opus`) or null (no mic). A Mac without permission hands over pure silence, not an error: `VoiceBar` detects it.
