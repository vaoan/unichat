# Java comments

- `*/` inside a comment closes it: markdown-ish `*italic*/_italic_` in Javadoc gave "illegal character" compile errors. No asterisk right before a slash in comments.
- Comments say why, in the code's words, as the code around them does; a lesson worth keeping goes to the folder's `CLAUDE.md` instead (root `CLAUDE.md`, "Learning from mistakes").
