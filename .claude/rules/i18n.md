# Texts the person reads

- Every user-facing text goes through `support/I18n` (`I18n.t("key")`, `I18n.n` for counts): `src/main/resources/app/unichat/i18n/messages.properties` (English, the fallback) and `messages_es.properties`. A new language is one more `messages_<code>.properties` (found by `I18n.available`, offered in Ajustes → Apariencia); `I18nTest` demands the same keys and placeholders in every file.
- The language changes live (`UnichatApp.relocalize` rebuilds the window), so never keep a text in a `static final` or anything built once.
- Spanish texts still written outside `ui` (errors from `matrix`, `server`…) are known debt (`docs/ARCHITECTURE.md`): don't add new ones.
